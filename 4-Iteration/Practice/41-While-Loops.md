### `Q1`
Define a function named `upcount` with the parameters `start`, `stop`, and `step`. 
* `start`, `stop`, and `step` each represent any integer value.

<br>

In the function definition write a while loop that prints out each value from `start` to `stop` inclusive on the same line with a space after each value and increasing by a value of `step` each iteration.

<br> 

Preconditions:
* `start` value must be less than `<` the value of `stop`
* The value of `step` must be positive (`step > 0`)

<br>

Constraints:
* You must use a while loop.
